## 📍📢 หมายเหตุเกี่ยวกับระบบ Comment
-ระบบแสดงความคิดเห็น (Comment System) ในโปรเจกต์นี้ยังไม่สามารถใช้งานได้ในเวอร์ชันออนไลน์ เนื่องจากข้อจำกัดของการเชื่อมต่อฐานข้อมูล
-ขณะพัฒนา ระบบถูกออกแบบให้เชื่อมต่อกับ ฐานข้อมูล MySQL ภายในเครื่อง (localhost) ผ่าน phpMyAdmin
-เมื่อทำการ Deploy ขึ้นเว็บไซต์ (ผ่านบริการ Render) พบว่า Render ไม่รองรับการประมวลผลไฟล์ .php และไม่สามารถเชื่อมต่อกับฐานข้อมูลที่อยู่ในเครื่องของผู้พัฒนาได้
-เพื่อความปลอดภัยและความเสถียรของระบบ Render ไม่อนุญาตให้เชื่อมต่อฐานข้อมูลภายนอกที่ไม่มีการเปิดใช้งานออนไลน์
-จึงทำให้ หน้าข้อมูลสถานที่ท่องเที่ยว และ ระบบ comment ไม่สามารถบันทึก/แสดงข้อมูลจากฐานข้อมูลได้ในขณะนี้
